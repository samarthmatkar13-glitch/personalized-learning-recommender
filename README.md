\# 🎓 Personalized Learning \& Course Recommendation System



An intelligent machine learning-based application that helps students discover relevant courses based on their learning activities and interests.



The system uses recommendation techniques and K-Means clustering to provide personalized course suggestions and analyze student learning patterns through an interactive dashboard.



\## 🚀 Project Overview



Choosing the right course can be difficult for students because of the large number of available learning resources.



This project aims to simplify course selection by analyzing student interactions and recommending suitable courses based on their learning patterns.



\## ✨ Key Features



\- \*\*Personalized Course Recommendations:\*\* Suggests relevant courses for students.

\- \*\*Recommendation Scores:\*\* Displays scores for recommended courses.

\- \*\*Student Clustering:\*\* Uses K-Means clustering to group students based on learning patterns.

\- \*\*Interactive Dashboard:\*\* Built using Streamlit.

\- \*\*Course Popularity Analysis:\*\* Visualizes popular courses.

\- \*\*Course Completion Analysis:\*\* Displays course completion statistics.

\- \*\*Dataset Overview:\*\* Provides insights into student and course data.

\- \*\*CSV Export:\*\* Allows users to export recommendation results.

\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/samarthmatkar13-glitch/personalized-learning-recommender.git

```



\### 2. Open the project folder



```bash

cd personalized-learning-recommender

```



\### 3. Install dependencies



```bash

pip install -r requirements.txt

```



\### 4. Run the application



```bash

python -m streamlit run app.py

```



\### 5. Open in browser



Streamlit will provide a local URL, usually:



```text

http://localhost:8501

```
